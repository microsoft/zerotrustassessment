# Application control (WDAC / App Control for Business) is enforced via Intune

App Control for Business, formerly Windows Defender Application Control, limits which apps and code can run on managed Windows devices. An assigned policy must be enforced rather than audit-only to prevent untrusted code from running after phishing, downloads, removable media, or supply-chain events. Plan deployments carefully so legitimate line-of-business apps are not blocked.
