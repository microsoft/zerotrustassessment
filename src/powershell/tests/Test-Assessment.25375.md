Global Secure Access onboards and operates only when the tenant holds a Microsoft Entra ID P1 license plus at least one Global Secure Access licensing entitlement — Microsoft Entra Internet Access, Microsoft Entra Private Access, the Microsoft Entra Suite (which bundles both), or Microsoft Agent 365. Microsoft Entra ID P1 is the foundational gate: if it is removed, the tenant is offboarded from Global Secure Access and its configuration is deleted. A tenant operating Global Secure Access without these entitlements is exposed on two fronts: administrators lose the supported path to remediate or evolve policy, and the deployment becomes subject to service interruption when entitlements lapse. This check verifies that the tenant holds an active Microsoft Entra ID P1 license and at least one active Global Secure Access licensing entitlement so the deployment remains supportable and resilient.

**Remediation action**

- Review the Global Secure Access licensing requirements and purchase the required tenant entitlements (Microsoft Entra ID P1 plus at least one Global Secure Access licensing entitlement — Microsoft Entra Internet Access, Microsoft Entra Private Access, Microsoft Entra Suite, or Microsoft Agent 365). For more information, see [Global Secure Access licensing overview](https://learn.microsoft.com/entra/global-secure-access/overview-what-is-global-secure-access?wt.mc_id=zerotrustrecommendations_automation_content_cnl_csasci#licensing).
- Consider the Microsoft Entra Suite, which bundles both Microsoft Entra Internet Access and Microsoft Entra Private Access in a single SKU. For more information, see [Microsoft Entra Suite](https://learn.microsoft.com/entra/fundamentals/concept-entra-suite?wt.mc_id=zerotrustrecommendations_automation_content_cnl_csasci).
- Purchase or extend Microsoft Entra ID P1 — removal of P1 will offboard the tenant from Global Secure Access and delete its configuration. For more information, see [Microsoft Entra ID licensing](https://learn.microsoft.com/entra/fundamentals/get-started-premium?wt.mc_id=zerotrustrecommendations_automation_content_cnl_csasci).
- Confirm purchased SKUs and entitlement status through the Microsoft 365 admin center Licenses blade. For more information, see [Microsoft 365 admin center — Licenses](https://admin.microsoft.com/Adminportal/Home#/licenses).
- Required roles to purchase or modify subscriptions: Billing Administrator or Global Administrator (least privileged is Billing Administrator). For more information, see [Microsoft Entra built-in roles](https://learn.microsoft.com/entra/identity/role-based-access-control/permissions-reference?wt.mc_id=zerotrustrecommendations_automation_content_cnl_csasci#billing-administrator).
