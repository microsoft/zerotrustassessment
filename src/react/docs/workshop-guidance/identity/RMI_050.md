# Change provisioning flow of existing users to Microsoft Entra ID

## Overview

Change the source of authority for existing users from on-premises Active Directory to Microsoft Entra ID. This lets organizations manage these users directly in the cloud, supporting a cloud-first identity strategy and reducing reliance on on-premises identity infrastructure.
