# Advanced SWG: Implement Cloud Firewall capabilities (Preview)

## Overview

Global Secure Access Cloud Firewall controls acquired traffic beyond ordinary web filtering. The client and remote-network sources use separate configuration guides:

- Client Cloud Firewall is available as a preview and requires the documented Internet Access acquisition rules.
- Remote-network Cloud Firewall supports five-tuple rules for branch traffic and is documented separately.
- Acquiring traffic and enforcing a firewall rule are separate steps. An acquisition rule does not itself block traffic.

Use a source-specific design and validate which protocols, ports, and destinations are acquired before relying on firewall enforcement.
