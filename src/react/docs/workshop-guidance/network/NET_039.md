# Advanced SWG: Implement Threat Intelligence filtering

**Implementation Effort:** Low - Reuses the network baseline where applicable, or requires a supported threat-intelligence policy.  
**User Impact:** Medium - Blocking and exceptions can affect legitimate destinations across the protected user and agent population.

## Overview

Global Secure Access (GSA) threat-intelligence filtering adds known malicious-domain and URL indicators to Secure Web Gateway (SWG) policies. Microsoft and third-party threat intelligence identifies high-severity destinations such as phishing sites, malware distribution points, botnets, and command-and-control servers.

Allow-list exceptions address false positives and business requirements. Supported security-profile and Conditional Access integration makes decisions context-aware, while traffic logs identify the matched threat type.

AI applications and agents can also follow attacker-controlled links or reach compromised services. Their acquired traffic should be considered within this shared network capability. This supports *Assume breach* by limiting known malicious outbound communications and *Verify explicitly* through policy decisions on the intended traffic path.

### Prerequisites

- Internet Access licensing, forwarding for the intended source, and the appropriate GSA/Conditional Access administrative roles.
- An accountable policy owner, supported profile assignment, and a controlled exception process.
- Transport Layer Security (TLS) inspection where HTTPS URL indicators require it; domain-level protection has different visibility requirements.
- For AI scenarios, complete [AI network readiness](../AI/AI_163.md), including source-specific acquisition.

### Limitations

- Copilot Studio uses its supported [baseline policy path](../AI/AI_027.md); other sources require their applicable profile configuration.
- Threat intelligence covers known malicious destinations, not every unsanctioned service, prompt injection, sensitive prompt, or dangerous tool. It complements [AI destination filtering](../AI/AI_025.md), [Model Context Protocol (MCP) restrictions](../AI/AI_191.md), and [network data loss prevention (DLP)](../AI/AI_192.md).
- A block by another endpoint or browser control does not establish that GSA enforced the decision.
- Safe validation must not depend on live malicious destinations or disabling production defenses. The configuration guide supplies controlled test guidance.
