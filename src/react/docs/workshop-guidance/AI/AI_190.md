# Acquire local AI agent web traffic with Global Secure Access

**Implementation Effort:** Medium - Requires selecting an acquisition mode, accounting for existing gateways, and planning a controlled rollout.  
**User Impact:** Medium - Routing changes or policy blocks can affect agents and existing user-traffic coverage.

## Overview

Agentic Acquire is an Internet Access forwarding policy that directs the Global Secure Access (GSA) client to acquire web traffic from local AI agents. It supports a deployment in which another Secure Web Gateway (SWG) continues to handle other user traffic.

This supports *Verify explicitly* by establishing the agent's network path and *Assume breach* by reducing unmonitored egress. Acquisition makes traffic available to supported controls; it does not itself enforce web, prompt, content, data loss prevention (DLP), or Model Context Protocol (MCP) policies.

### Prerequisites

- Complete [AI network readiness](./AI_163.md), including Internet Access licensing, Global Secure Access Administrator access, assignments, and bypass review.
- Supported Windows or macOS clients. The supplied guidance lists minimum GSA versions **2.31.125** and **1.1.26030604**, respectively; the linked configuration guide is authoritative for current requirements.
- An inventory of local agents and destinations, with routing ownership agreed with existing SWG/VPN administrators.
- A pilot scope, recovery plan, and understanding of traffic already protected by other acquisition modes.

### Limitations

- Agentic Acquire is not mandatory when an existing full or selective Internet Access deployment already provides the required forwarding.
- Disabling other acquisition modes can remove existing user coverage; agent-only acquisition is not a harmless replacement for a broader deployment.
- Support for local-agent web traffic does not imply coverage of all processes, protocols, agents, remote networks, or hosted Copilot Studio traffic.
- Nonstandard-port and UDP acquisition for [cloud firewall](./AI_193.md) must be planned separately.
- Agent registration is not acquisition, and acquired traffic is not automatically inspected or denied.
