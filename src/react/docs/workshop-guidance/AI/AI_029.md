# Configure inline prompt injection protection with Global Secure Access

**Implementation Effort:** Medium - Requires acquisition, inspection, prompt rules, conversation schemes, and policy assignment.  
**User Impact:** Medium - Detected malicious prompts and rate-limited requests can be blocked, affecting otherwise legitimate workflows.

## Overview

Prompt Injection Protection in Microsoft Entra Internet Access inspects supported outbound prompt requests and can block detected adversarial prompts and jailbreak attempts before they reach the destination application.

This supports *Assume breach* by adding a network defense independent of application code and *Verify explicitly* by evaluating supported prompt content. It complements application-side safety controls and least-privilege tool authorization rather than replacing them.

### Prerequisites

- Complete [AI network readiness](./AI_163.md), including Internet Access acquisition for the intended applications.
- Internet Access licensing, Global Secure Access Administrator access, and Conditional Access Administrator access.
- The documented setup uses Windows devices or virtual machines that are Microsoft Entra joined or hybrid joined.
- A trusted Transport Layer Security (TLS) inspection certificate and policy covering the target HTTPS traffic.
- Conversation schemes matching the applications' request formats, with an active security profile and appropriate user/group assignment.

### Limitations

- Supports text prompts in JSON-based generative AI applications; files are not supported.
- Prompts beyond 64,000 characters are truncated. Requests exceeding scanning rate limits are blocked.
- Application coverage depends on correct extraction and acquisition, not the application brand. Custom formats need [custom conversation schemes](./AI_031.md).
- Report-only assignment is not evidence of blocking.
- Copilot Studio forwarding excludes its own language-model orchestration and result-enhancement requests; enabling that integration does not prove those requests receive prompt protection.
