# Verify agent identity attribution and downstream control eligibility

**Implementation Effort:** Medium - Requires correlating source, registry, identity, and authentication information for each selected integration.  
**User Impact:** Low - Read-only assessment does not enable policies or migrate identities.

## Overview

An agent's presence in a registry does not establish which principal it uses to access resources or which controls apply. Microsoft Entra agent identities, optional agent user accounts, human delegated access, and source-platform identities are not interchangeable.

This supports *Verify explicitly* by connecting an agent to its actual authentication path and *Use least privilege access* by selecting controls that apply to that path. It provides a handoff from discovery to policy deployment without treating inventory as proof of enforcement.

### Prerequisites

- Representative integrations and accountable source-platform owners.
- Read access to the relevant source platforms, registry, identity records, and sign-in/resource-access evidence.
- Documented identifiers and relationships sufficient to correlate records; one reader role does not grant access to every system.
- An approved benign workload interaction and evidence-handling arrangements that exclude credentials, raw tokens, and sensitive prompts.

### Limitations

- Matching display names are not enough. Detected or Virtual identifiers do not prove native Entra authentication.
- A logged user does not necessarily identify the agent subject or actor; available context depends on the supported records and authentication path.
- Control eligibility varies by platform, operating system, and integration. Unsupported, unverified, or pending capabilities must remain distinct from verified ones.
- Registry synchronization does not automatically provide native identity or code-level integration. SDK adoption is not a universal prerequisite for registry sync.
- Eligibility assessment is not proof of enforcement and is not authorization to create a replacement identity or migrate an existing one.
