# 144: Delivery Optimization

**Implementation Effort:** Medium — policy setup is simple, but network-aware design and validation take coordination.

**User Impact:** Low — users usually notice only faster downloads, though poor configuration can consume unwanted local or WAN bandwidth.

## Overview
Delivery Optimization helps Windows devices share update and application content efficiently so organizations reduce redundant internet downloads and improve rollout speed. In a Zero Trust device program, it is not a primary access-control feature, but it is an important enabler for keeping managed devices updated quickly at scale. Better content distribution supports faster patch compliance, especially for remote, branch, or bandwidth-constrained populations.

## Implementation Guidance
- Decide how peers should be grouped for your environment, such as by NAT boundary, site, Microsoft Entra group, or other supported grouping logic. The grouping model determines whether Delivery Optimization helps or harms network performance.
- Configure Delivery Optimization settings with Intune for download mode, peer behavior, bandwidth limits, cache policies, and any restrictions required for mobile or metered scenarios.
- Review how Delivery Optimization should behave on VPN-connected devices. Many organizations intentionally reduce or disable peer-sharing over VPN to avoid saturating tunnels.
- Coordinate with network and branch-office teams if you also use Microsoft Connected Cache, proxy controls, or other update-distribution technologies.
- Pilot with representative branch, home, and campus networks so you can validate actual bandwidth savings rather than relying on default assumptions.
- Use reporting to confirm content is being shared as expected and that no device class is disproportionately downloading from the internet.
