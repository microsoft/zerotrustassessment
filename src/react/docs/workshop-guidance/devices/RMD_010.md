# 010: Multi-Admin Approval

**Implementation Effort:** Medium – Requires approval policy design and governance of approver groups.

**User Impact:** Low – The feature changes admin workflow more than user experience.

## Overview
Multiple administrative approval in Microsoft Intune is intended for sensitive administrative changes where one person should not be able to act alone. The control is most valuable for actions that can weaken security, disrupt many devices, or bypass established change control. Within a Zero Trust model, it helps enforce assume-breach principles by making it harder for a single compromised account to silently push a harmful change.

## Implementation Guidance
1. Identify supported Intune resources where a second-person approval materially lowers risk, such as scripts or app-related changes supported by the feature at the time of deployment.
2. Use separate approver groups from requestor groups and document conflict-of-interest rules so approvals are independent.
3. Define what constitutes a normal change, an urgent change, and an incident-response change, and align approval expectations accordingly.
4. Monitor pending approvals and rejections so security-critical work does not stall unnoticed.
5. Retain audit evidence and review patterns such as repeated emergency approvals or frequent rejected requests.
6. Combine this feature with RBAC, privileged device requirements, and role activation controls instead of treating it as a standalone safeguard.
