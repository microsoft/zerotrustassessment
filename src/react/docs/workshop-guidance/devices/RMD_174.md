# 174: Device config policies through settings catalog

**Implementation Effort:** Medium  
**User Impact:** Low to Medium

## Overview

The Intune settings catalog provides a broad, searchable way to configure macOS device settings without relying exclusively on older profile templates. It is useful when you need more granular configuration and want to standardize policy creation in a single management plane.

For Zero Trust, settings catalog profiles help enforce consistent security controls on managed Macs, but they must be designed carefully so multiple teams do not create overlapping profiles that conflict or become hard to troubleshoot.

## Implementation Guidance

### Design the profile structure
- Group settings by purpose, such as security baseline, privacy permissions, authentication experience, or user experience, instead of creating one oversized profile.
- Establish a naming standard and ownership model so admins can identify which team manages each profile.
- Review whether a setting already exists in another template or baseline before adding it to a new settings catalog profile.

### Configure and assign
- Create the macOS settings catalog profile in the Microsoft Intune admin center and add only the settings that are needed for the target outcome.
- Use test groups first and validate the device-side behavior, especially for privacy preferences, login items, background services, and restrictions that may affect end-user workflows.
- Document settings that intentionally differ by department or device role so those differences are not mistaken for policy drift.

### Monitor and maintain
- Use profile reporting and support diagnostics to identify unsupported settings, conflicts, and assignment issues.
- Retire template-based or custom-profile duplicates when an equivalent settings catalog implementation replaces them.
- Review macOS release notes regularly because available settings and behaviors can change with new operating system versions.
