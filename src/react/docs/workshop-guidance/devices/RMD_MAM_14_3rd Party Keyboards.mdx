# 3rd Party Keyboards for iOS

**Implementation Effort:** Low

**User Impact:** Medium

## Overview
On iOS and iPadOS, Intune app protection can restrict third-party keyboard use in supported managed apps so that work data entry stays within more trusted input paths. This is a useful Zero Trust control where the organization wants to reduce the risk of data capture by keyboard extensions.

Because some users rely on third-party keyboards for accessibility, multilingual input, or productivity, the organization should treat this as a policy decision that requires communication, testing, and an exception process.

## Implementation Guidance
1. In the Microsoft Intune admin center, edit the applicable **iOS/iPadOS** app protection policy and review the keyboard and input controls documented for APP on that platform.
2. Enable the setting that restricts third-party keyboards in supported managed apps. Confirm the exact current UI text in Microsoft Learn before publishing final workshop guidance.
3. Pilot with users who depend on different input methods, especially accessibility scenarios, before broad enforcement. Document what happens in Outlook, Teams, and Microsoft 365 apps when the restriction is active.
4. Coordinate with user communications so employees understand that the restriction applies when entering organizational data in managed apps, not necessarily across the whole personal device.
5. Maintain an exception path for validated accessibility or language-input needs if the business determines the risk can be accepted with compensating controls.
