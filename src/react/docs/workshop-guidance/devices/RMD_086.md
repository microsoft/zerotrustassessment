# 086: FLW / Shared Devices

**Implementation Effort:** High  
**User Impact:** High

## Overview
Frontline and shared devices support task-oriented work in retail, healthcare, logistics, manufacturing, and field operations. These devices usually need fast access to a limited set of apps, predictable sign-in behavior, strong physical security assumptions, and simple recovery when a device is lost or handed to another worker.
In Zero Trust terms, shared devices should expose only the minimum apps and settings necessary, authenticate users explicitly where user context matters, and be easy to return to a known-good state. Intune supports these patterns through Android Enterprise dedicated devices, fully managed shared-use scenarios, kiosk controls, app pinning, and launcher customization.

## Implementation Guidance
1. Choose the correct device mode: dedicated for single-purpose or tightly shared task devices, fully managed for individually assigned corporate devices, and only allow personal use where the business genuinely requires it.
2. Standardize the user experience with Managed Home Screen or another supported launcher pattern so workers see only the approved apps, sign-in prompts, and workflows they need.
3. Assign only essential apps, certificates, Wi-Fi, VPN, and compliance policies. Shared devices should avoid broad access and should use device-based group targeting where appropriate.
4. Plan operational behavior such as shift change, shared sign-in/out, password reset, remote help, device replacement, and automatic reprovisioning after a wipe or failure.
5. Use update rings, maintenance windows, and pilot groups to keep devices current without disrupting business-critical hours.
6. Monitor battery health, connectivity, app crash rates, and physical break/fix patterns; these matter more on frontline devices than on typical knowledge-worker phones.
