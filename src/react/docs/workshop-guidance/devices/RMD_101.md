# 101: Remote actions

**Implementation Effort:** Medium  
**User Impact:** Medium

## Overview
Remote actions in Microsoft Intune let administrators trigger management tasks on supported devices without physical access. Depending on platform support, these actions can include sync, restart, passcode reset, key rotation, diagnostics collection, retire, wipe, and other operational controls.
In Zero Trust operations, remote actions are powerful and should be treated as controlled administrative interventions. The right action depends on whether the device is personally owned or corporate-owned, whether the situation is routine support or active incident response, and whether data preservation is required.

## Implementation Guidance
1. Document which remote actions are approved for each ownership and platform scenario. For example, retire is often preferable for BYOD, while wipe may be correct for a lost corporate device.
2. Use Intune RBAC and scope tags so only authorized roles can execute high-impact actions.
3. Train support teams on pre-checks and post-checks: verify device identity, confirm user status, understand data impact, and verify whether additional Microsoft Entra actions are needed.
4. For incident response, coordinate remote actions with account disablement, token revocation, and evidence-collection requirements.
5. Review action status after execution; do not assume a remote command succeeded simply because it was submitted.
6. Audit usage periodically to detect overuse, misuse, or training gaps in the support organization.
