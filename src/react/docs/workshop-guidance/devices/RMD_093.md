# 093: Store app deployment

**Implementation Effort:** Low to Medium  
**User Impact:** Low

## Overview
Store app deployment for Android in Microsoft Intune typically uses Managed Google Play as the governed source for public applications. This allows administrators to approve apps centrally, synchronize them into Intune, and assign them to users or devices with consistent lifecycle management.
In a Zero Trust model, store apps should still be part of a controlled path: approved app source, approved version or update strategy, appropriate app configuration, and access controls that limit corporate data exposure inside the app.

## Implementation Guidance
1. Connect the tenant to Managed Google Play if that prerequisite has not already been completed.
2. Approve only the apps that have passed business and security review, and confirm whether any permissions or in-app dependencies affect the deployment experience.
3. Synchronize approved apps into Intune, then choose the correct assignment intent: required, available, or uninstall.
4. Where supported, pair store app deployment with app configuration policies, managed app settings, and app protection policies so users land in the secure configuration immediately.
5. Use pilot groups and phased rollout for critical apps rather than assigning to the entire population on day one.
6. Monitor install status, version drift, and sign-in failures, and coordinate with app owners when vendor updates change behavior.
