# 176: AV/EDR

**Implementation Effort:** High  
**User Impact:** Low to Medium

## Overview

For macOS, antivirus and endpoint detection and response are typically delivered through Microsoft Defender for Endpoint, with Intune used to deploy the app and the supporting configuration required by macOS. This gives security teams visibility and protection across Apple endpoints that participate in Microsoft security operations.

In Zero Trust, AV and EDR provide device-health and threat posture signals that complement enrollment and compliance. A managed Mac should not only be enrolled; it should also be capable of detecting, preventing, and reporting malicious behavior.

## Implementation Guidance

### Prepare the macOS security prerequisites
- Confirm that devices meet the supported macOS version and Microsoft Defender for Endpoint requirements before assignment.
- Plan the necessary configuration profiles for system extensions, network extensions, notifications, background services, and full disk access where required.
- Coordinate with the Microsoft Defender security team so onboarding packages, tenant association, and alert routing are ready before rollout.

### Deploy the service through Intune
- Package or assign the Defender for Endpoint app in Intune using the supported macOS app type and deployment method.
- Create the prerequisite macOS configuration profiles first so users are not prompted manually for permissions that should be managed by policy.
- Assign the EDR or onboarding policy only after the client and prerequisites are confirmed on pilot devices.

### Validate protection outcomes
- Confirm the device appears in both Intune and Microsoft Defender with the expected health state and sensor onboarding status.
- Test malware detection and policy enforcement in a safe validation method approved by the security team.
- Review update cadence, exclusion governance, and device performance feedback before broad deployment.
