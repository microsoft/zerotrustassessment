# 143: Quality Updates

**Implementation Effort:** Medium — monthly servicing is routine, but emergency patch workflows and hotpatch eligibility need disciplined operations.

**User Impact:** Low to Medium — standard quality updates can usually be handled quietly, but emergency security patches and restart behavior still need planning.

## Overview
Quality updates deliver the monthly Windows security and reliability fixes that keep managed endpoints resistant to known vulnerabilities. In a Zero Trust model, rapid and measurable application of quality updates is critical because device trust should decay when patch latency grows. Microsoft Intune supports normal servicing through update rings and urgent response through expedited quality update policies, while hotpatching can reduce restart requirements for supported scenarios.

## Implementation Guidance
- Use update rings to define the normal monthly quality-update cadence, including deployment order, restart experience, and deadlines across pilot and production rings.
- Create and test an expedited quality-update process in advance so the organization can rapidly respond to zero-day vulnerabilities or high-severity out-of-band releases.
- If you plan to use hotpatching, validate supported Windows editions, servicing prerequisites, licensing requirements, and any Microsoft-managed update dependencies before you describe it as a standard capability.
- Coordinate emergency patching with security operations, incident response, and business communications so urgent fixes can bypass normal deferrals without creating confusion.
- Track success, failure, and restart compliance through Intune reporting and any connected monitoring platforms so emergency deployments can be audited after the fact.
- Document when to pause or rollback a bad quality update and who can authorize that decision.
