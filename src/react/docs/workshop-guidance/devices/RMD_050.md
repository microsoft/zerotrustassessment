# 050: Managed Edge Browser

**Implementation Effort:** Medium

**User Impact:** Medium

## Overview
Microsoft Edge for iOS and Android is Microsoft’s managed mobile browser and is commonly used to provide a safer, policy-aware browsing experience for organizational web access. In a Zero Trust program, Edge matters because it can participate in app protection policy scenarios, receive app configuration, and help direct users to approved web experiences on managed and unmanaged mobile devices.

For many organizations, Edge is most valuable when paired with Conditional Access and app protection policies so organizational web data stays within a protected app boundary.

## Implementation Guidance
1. Decide whether Edge is required for **enrolled devices**, **personally owned BYOD devices**, or both.
2. Deploy Edge as a managed app from Intune and assign it to pilot users before wider rollout.
3. Use **app configuration policies** to set approved account behavior, allowed data-transfer settings, home page or managed bookmarks where appropriate, and any required browser experience controls documented by Microsoft.
4. Pair Edge with **app protection policies** if the goal is to protect browser-accessed organizational data on mobile devices that are not fully enrolled.
5. Review Conditional Access policies for Microsoft 365 and internal web apps so they align with your browser strategy. Where applicable, require a compliant device or an approved/protected app path instead of allowing unmanaged browser access.
6. Test work/personal account separation, sign-out behavior, link handling from Outlook and Teams, and downloads or copy/paste restrictions before production rollout.
