# 065: iOS Updates

**Implementation Effort:** Medium

**User Impact:** Medium

## Overview
Keeping Apple devices on a supported OS version is a core Zero Trust requirement because known vulnerabilities and missing platform capabilities can make other controls less effective. Microsoft Intune can manage software update behavior for supervised iOS/iPadOS devices so organizations can reduce risk while still giving users predictable maintenance windows.

Update design is not only about speed. It is also about business continuity, compatibility testing, and clear communications.

## Implementation Guidance
1. Confirm which Apple devices are supervised and therefore eligible for the update controls you plan to use.
2. Define your update strategy: how quickly critical security updates should install, how long feature updates may be deferred, and which user groups need longer pilot periods.
3. Create separate update policies for pilot users, broad production users, and any specialty or shared devices that require tighter maintenance windows.
4. Align compliance policy with the update strategy. If you enforce minimum OS version, ensure users have a realistic path to update before devices are blocked.
5. Test update behavior on enrolled supervised devices, including charging, network dependency, user prompts, and the timing of scheduled installs.
6. Review update reports and exception processes regularly so unsupported devices do not quietly remain in use.
