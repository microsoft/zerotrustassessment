# 047: RBAC

> **Implementation Effort:** Medium  
> **User Impact:** Low for users; Medium for admins

## Overview
Microsoft Intune RBAC should be designed so administrators have only the permissions, object visibility, and scope they require. This is fundamental to Zero Trust administration and should be treated as an architectural control rather than a convenience feature.

## Implementation Guidance
1. Map job functions to permissions before assigning roles.
2. Use built-in roles where appropriate, but remove unnecessary rights through custom roles when needed.
3. Combine role assignments with scope tags and scope groups.
4. Separate high-risk functions such as policy creation, broad deployment, and destructive remote actions when possible.
5. Use Microsoft Entra privileged access controls for higher-risk roles.
6. Review and recertify assignments regularly.

The safest RBAC design is explicit, scoped, and regularly audited.
