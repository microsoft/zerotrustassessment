# 075: Shared iPad

**Implementation Effort:** High

**User Impact:** Medium to High

## Overview
**Shared iPad** is an Apple capability for supported supervised iPads that allows multiple users to sign in to the same device while keeping their apps and data separated in local partitions. In Microsoft Intune, Shared iPad is appropriate for education, clinical, retail, and other shift-based or communal-use cases where users need a more personalized experience than a simple kiosk provides.

From a Zero Trust perspective, Shared iPad helps preserve user separation on a physically shared device, but it still requires careful planning for identity, app support, compliance, and sign-out behavior.

## Implementation Guidance
1. Confirm that the use case truly requires **Shared iPad** rather than standard assigned iPads or **Microsoft Entra shared device mode** for supported apps.
2. Use a supervised Apple enrollment path, typically through **Apple Business Manager** or **Apple School Manager**, and create the appropriate Intune enrollment profile for Shared iPad.
3. If you plan to use **Managed Apple IDs** and federation with Microsoft Entra ID, coordinate identity setup with the Apple administrators before rollout.
4. Pilot sign-in speed, local storage capacity, app behavior across multiple users, and what happens when the device is offline or full.
5. Validate Conditional Access, required apps, certificates, and any classroom or frontline workflows with real devices before scaling.
6. Train support staff on how Shared iPad differs from Shared Device Mode and on when wiping or reassigning a device is necessary.
