# 175: Deploy macOS SSO extension

**Implementation Effort:** High  
**User Impact:** Medium

## Overview

For modern macOS identity experiences, organizations should evaluate Microsoft Entra Platform SSO rather than treating the feature as just a generic 'SSO extension.' Platform SSO can improve sign-in consistency, strengthen device-to-identity integration, and reduce repeated prompts for managed Macs.

In a Zero Trust design, the value of Platform SSO is not convenience alone. It can improve confidence that the signed-in user, device registration state, and downstream access controls are aligned before access is granted to business resources.

## Implementation Guidance

### Confirm prerequisites and target scenario
- Verify the supported macOS version, Intune Company Portal version, Microsoft Entra configuration prerequisites, and hardware capabilities for the chosen Platform SSO mode.
- Decide whether the goal is password synchronization, passwordless sign-in, secure enclave-backed credentials, or another supported pattern.
- Limit the initial pilot to corporate-owned, fully managed devices unless there is a strong reason to test broader scenarios first.

### Deploy Platform SSO in Intune
- Create the appropriate macOS configuration profile in the Microsoft Intune admin center and configure the Platform SSO settings according to the supported Microsoft Entra scenario.
- Coordinate with enrollment, local account creation, FileVault, and compliance policy so the user journey remains coherent from first sign-in onward.
- Test first-run registration, sign-in prompts, password changes, and app access for Microsoft 365 and other federated applications.

### Operate and support
- Prepare support staff to troubleshoot registration failures, stale credentials, and device re-registration scenarios.
- Monitor adoption and sign-in behavior before expanding the rollout to all managed Macs.
- Review whether Platform SSO changes local account expectations or break-glass admin processes.
