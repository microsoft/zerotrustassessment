# 134: Browser

**Implementation Effort:** Medium — browser hardening is straightforward technically, but extension governance, identity integration, and data protection decisions usually need stakeholder alignment.

**User Impact:** Low to Medium — most users can continue working normally, but browser profile separation, extension controls, and download restrictions may change familiar behavior.

## Overview
For many organizations, the browser is the primary access point to corporate data. Microsoft Edge is therefore a major Zero Trust control surface, not just a productivity application. Managed browser settings can help enforce work identity separation, secure defaults, phishing and malware protection, extension governance, download controls, and compatibility with Microsoft Entra Conditional Access and Microsoft Defender for Endpoint-based protections.

## Implementation Guidance
- Standardize which browser is supported for work access scenarios and define whether Microsoft Edge should be the required or recommended browser on managed Windows devices.
- Use Intune policy to configure security-relevant browser settings such as SmartScreen, password manager behavior, download restrictions, startup pages, profile sign-in, extension allow or block lists, and developer tool restrictions where justified.
- Where users access corporate resources from mobile devices, align browser guidance with Intune app protection policies and approved-app requirements so work data stays within managed app boundaries.
- If your risk model requires it, pair browser hardening with web protection, Defender for Endpoint signals, and Conditional Access policies that require device compliance or app protection before access is granted.
- Test business-critical web apps, legacy authentication flows, and required extensions before broad rollout; browser hardening often fails because compatibility and change management are not addressed early.
- Review policies regularly as Edge security features evolve, and remove legacy exceptions that were created only to support old apps.
