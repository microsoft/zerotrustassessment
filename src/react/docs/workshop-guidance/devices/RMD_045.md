# 045: Data protection framework using App protection

> **Implementation Effort:** Medium  
> **User Impact:** Medium

## Overview
The Intune app protection data protection framework helps administrators translate Zero Trust principles into concrete policy design by mapping user populations to Level 1 (Enterprise basic), Level 2 (Enterprise enhanced), and Level 3 (Enterprise high) data protection tiers.

For Zero Trust, the framework is a way to phase protection based on risk instead of forcing the same control set onto every mobile user.

## Implementation Guidance
1. Define risk-based mobile user tiers before you create policies.
2. Establish a **minimum baseline** for all users that keeps work data inside protected apps.
3. Add **enhanced controls** for users who access confidential or regulated information.
4. Reserve the **highest restrictions** for users or roles at elevated risk, such as privileged admins or highly targeted executives.
5. Keep the framework aligned to Microsoft Entra Conditional Access and your mobile app portfolio.
6. Pilot each level separately and publish clear support guidance.
7. Reassess the framework when new Intune app protection capabilities become available.

The framework should help answer "what do we deploy first?" and "what gets stricter for higher risk?" rather than simply naming three levels.
