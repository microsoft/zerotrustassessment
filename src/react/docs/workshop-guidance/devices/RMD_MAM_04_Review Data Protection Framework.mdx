# Review Data Protection Framework

**Implementation Effort:** Medium

**User Impact:** High

## Overview
The Intune app protection data protection framework is intended to help organizations standardize MAM settings at increasing levels of protection. In a Zero Trust workshop, the value of the framework is not the labels alone; it is the repeatable decision model that maps data sensitivity, user risk, and usability needs to concrete Intune settings.

Most organizations should define a baseline mobile app protection profile for all users, a stricter profile for users who access sensitive business data, and a high-protection profile for privileged, regulated, or high-risk users. This avoids one-size-fits-all policies while still keeping policy sprawl manageable.

## Implementation Guidance
1. Start with the Microsoft app protection framework guidance and translate it into your own three-tier policy model, for example: **Baseline**, **Enhanced**, and **High Protection**.
2. For each tier, define the expected settings in the Intune admin center: data transfer restrictions, allowed save locations, backup behavior, PIN and biometric requirements, timeout values, offline grace periods, rooted and jailbroken response, threat signals, and browser handling.
3. Create separate app protection policies per platform and per tier. Assign them to clearly defined user groups such as all mobile users, sensitive-data users, and high-risk or privileged roles.
4. Pair the tiers with matching **Conditional Access** controls where appropriate. For example, high-protection users may require additional access conditions or shorter sign-in frequency expectations beyond the app-layer policy.
5. Document exceptions explicitly. If a business workflow needs copy and paste or save-as behavior that is blocked in the baseline tier, capture the justification, approval path, and compensating controls.
6. Review the framework at least quarterly or whenever Microsoft ships major changes to supported APP settings, platform capabilities, or dependent services such as Microsoft Defender for Endpoint and Microsoft Edge.
