# 072: RBAC

**Implementation Effort:** Medium

**User Impact:** Low

## Overview
Role-based access control (RBAC) in Microsoft Intune lets organizations delegate device and app administration without giving every operator full tenant-wide control. In a Zero Trust administrative model, RBAC is essential because administrator access should be limited to only the resources and actions each team truly needs.

Good Intune RBAC design reduces accidental change risk and makes audit review much easier.

## Implementation Guidance
1. Start with job functions: help desk, app admins, endpoint security admins, enrollment operators, and regional IT. Map permissions to real tasks, not to broad titles.
2. Use built-in Intune roles where they meet the need; create **custom roles** only when the built-ins are too broad or too narrow.
3. Apply **scope tags** and role assignments so delegated admins only see the devices, apps, and policies relevant to their region or business unit.
4. Review how Intune RBAC interacts with **Microsoft Entra ID** roles and any broader privileged-access controls in your tenant.
5. Test with representative admin accounts before rollout. Confirm what each role can see, edit, deploy, and remote-wipe.
6. Re-certify role assignments regularly and remove stale delegated access promptly.
