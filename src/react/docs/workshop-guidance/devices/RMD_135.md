# 135: VDI Strategy

**Implementation Effort:** High — VDI and Cloud PC decisions affect identity, networking, app delivery, endpoint management, licensing, and operational support models.

**User Impact:** Medium to High — virtual desktop decisions change how users access apps, store data, sign in, and receive support.

## Overview
A Zero Trust device program should not assume every worker needs a traditional, fully managed physical endpoint. Virtual desktop options such as Azure Virtual Desktop and Windows 365 can be effective for contractors, bring-your-own-device access, privileged workloads, call centers, and rapid onboarding scenarios. The security value comes from centralizing the compute environment, reducing data persistence on unmanaged endpoints, and layering strong identity, session, and device controls around access.

## Implementation Guidance
- Start with use cases, not product preference. Identify which populations need persistent personal desktops, pooled desktops, shared apps, contractor access, privileged administration, or quick temporary provisioning.
- Choose the service model intentionally: Windows 365 is typically simpler for persistent Cloud PCs, while Azure Virtual Desktop provides more flexibility for pooled, published-app, or specialized designs.
- Define how the virtual desktop environment will be joined, managed, and secured, including Microsoft Entra integration, Intune management where supported, Microsoft Defender for Endpoint onboarding, and security baseline alignment.
- Use Conditional Access, MFA, session restrictions, and logging to control entry into the virtual desktop service. Treat the sign-in path and the session itself as separate control points.
- Document clipboard, drive redirection, printing, copy and paste, and local device integration decisions for each workload sensitivity level. These settings often determine whether the design actually reduces data leakage risk.
- Establish patching, image management, backup, and incident-response ownership for session hosts or Cloud PCs before production rollout.
