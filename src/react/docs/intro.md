# Introduction to the Workshop and Assessment

Implementing a Zero Trust strategy can pose many challenges, such as knowing where to start, what order to implement things in, and how to accurately measure success towards achieving a secure Zero Trust posture. The Microsoft Zero Trust Workshop aims to tackle these problems and simplify the Zero Trust journey via two tools: the Zero Trust Workshop and the Zero Trust Assessment.

## Microsoft Zero Trust Workshop

The Zero Trust Workshop Tool is a Single-Page Application (SPA) that enables customers to document their current Zero Trust progress and develop an actionable roadmap for moving forward.

**Best for:** Stakeholder discussions and roadmap planning.

[Watch the workshop introduction](./videos/IntroductionToZT.md).

## Microsoft Zero Trust Assessment

The Zero Trust Assessment is a PowerShell module that can be run on your environment to confirm a strong security baseline. Running the PowerShell module on your tenant automatically provides you with a set of programmatically-generated recommendations based on your tenant's current configuration and activity data.

**Best for:** Automated tenant checks and baseline tracking.

[Watch the assessment overview](./videos/Assessment.md).

## Supported pillars

The Workshop supports planning across all eight pillars. The Assessment provides automated checks across seven; it does not currently assess DevSecOps.

| Pillar | Workshop | Assessment |
| --- | --- | --- |
| Identity | Yes | Yes |
| Devices | Yes | Yes |
| Data | Yes | Yes |
| Network | Yes | Yes |
| Infrastructure | Yes | Yes |
| Security Operations | Yes | Yes |
| Artificial Intelligence | Yes | Yes |
| DevSecOps | Yes | No |
