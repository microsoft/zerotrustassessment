# Support

## Is this an official Microsoft product?

No. Zero Trust Assessment is a community project maintained by Microsoft employees. It is **not an official Microsoft product**. The tool is provided as-is and is **not supported through any Microsoft support program or service**. Please do not open Microsoft support cases for issues with this tool.

## How to file issues and get help

Read the [installation and operating guide](src/powershell/doc/readme.md) and its [troubleshooting tips](src/powershell/doc/readme.md#troubleshooting) first.

This project uses [GitHub Issues](https://github.com/microsoft/zerotrustassessment/issues) for bugs and feature requests. Search existing issues before opening a new one. Include the assessment version, PowerShell version, affected pillar or test IDs, and a sanitized description of the problem and reproduction steps.

Community maintainers may investigate issues, but there is no guaranteed response time, resolution, or support service-level agreement.

### Protect tenant data when reporting an issue

Reports, exported data, support packages, and logs can contain personal information and sensitive tenant configuration. **Do not attach them unreviewed to public issues.** Review and redact any excerpt before posting it. Share additional diagnostics only through a private channel approved by your organization and agreed with the recipient.

See [log locations and diagnostic collection](src/powershell/doc/readme.md#logs-and-diagnostic-files) for what each artifact contains. Creating a support package does not submit it to Microsoft or establish a support entitlement.

## Microsoft Support Policy

The resources above provide community guidance only. They do not change the tool's as-is status or create official Microsoft support coverage.
